# Real Life More Studio - Multi-Agent Dashboard

"Real Life More Studio" is a premium, high-retention content creation suite tailored for documentary-style geography and earth science content creators on YouTube and Instagram Reels. 

The application utilizes a sequence of 3 specialized AI agents to analyze complex geographical science, script engaging video narratives, and compile viral growth SEO metadata.

---

## Key Features

1. **🤖 Agent 1: The Geo-Director**
   - Conducts scientific geo-research.
   - Formulates a sequential **Visual Blueprint Table** detailing what media clips or 3D animations to use (e.g. Google Earth Studio, Pexels) for every narrative beat.
   
2. **🤖 Agent 2: The Scriptwriter**
   - Generates long-form **YouTube scripts (3-5 mins)** with integrated psychological hooks, structured chapters, and inline visual cues.
   - Generates short-form **Instagram Reels scripts (50-60 secs)** containing instant attention grabbers and a **Seamless Loop Line** (infinitely repeating voiceover structure).

3. **🤖 Agent 3: The SEO & Growth Manager**
   - Curates 3 high-click-through-rate (CTR) video titles.
   - Outputs keyword-rich SEO descriptions and 15 highly-searched tags.
   - Provides optimized Instagram caption templates ending in comment-driving call-to-actions, accompanied by 20 viral hashtags.

4. **🎤 Interactive Teleprompter**
   - A full-screen overlay scrolling utility with custom speed controls, variable font resizing, and a center focal guide to assist content creators in voice recording.

5. **📂 Local Script Vault**
   - Locally caches past runs allowing instantaneous reload of previous agent responses.

---

## How to Run

1. **Direct Launch**:
   Simply double-click the `index.html` file or open it in any modern browser.

2. **API Access**:
   Get a free API key from the [Google AI Studio](https://aistudio.google.com/) and paste it into the "Gemini API Key" field in the sidebar. This key is stored securely in your browser's local storage and is never sent to any external server other than Google's official Gemini API endpoint.

3. **Demo Mode**:
   Don't have an API key? Click the **"Use Demo Mode"** button to run a simulated pipeline on any topic (or default ones like "Mariana Trench" or "Green Sahara") to see the dashboard in action.
